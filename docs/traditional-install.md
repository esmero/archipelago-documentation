## Traditional + Virtual Machine Installation Notes

For those who prefer classic or virtual machine approaches to system installation and configuration (instead of Dockerized deployment), this page is reserved for notes, recommendations, and guides.

* [Giancarlo Birello](https://github.com/giancarlobi) is maintaining and sharing the following documentation:
    * [Dev DBOpen: developer site of the DBOPen project](https://devdbopen.byterfly.eu/doku.php?id=start)
    * Includes an [Architecture overview](https://devdbopen.byterfly.eu/doku.php?id=architecture) and [Step by Step instructions](https://devdbopen.byterfly.eu/doku.php?id=stepbystep)

* Paul Wentzell (Briscoe Center for American History, UT Austin) prepared an Archipelago DEV Virtual Machine instance, using a Virtualbox install for Archipelago 1.5.0:
    * [Video tutorial recording here](https://drive.google.com/file/d/1r3bqaiNagi9CLAZkICFh_c3rQptR_GgQ/view?usp=sharing)
